# 搬移與資料保存

## 換電腦或換資料位置

### 複製資料庫

1. 停止舊位置的 `npm start`。
2. 將 `data/wall.db` 複製到新位置的 `data/`，或設定 `WALL_DB` 指向新位置的檔案。
3. 在新位置執行 `npm install` 和 `npm start`。
4. 用 `http://127.0.0.1:3000/` 或 `http://localhost:3000/` 開啟；若設定 `WALL_PORT`，改用該埠。

這種方式會帶走牆、圖片、備份、AI 提案、AI 紀錄與對話紀錄。複製前請先完整停止服務，避免 SQLite 正在寫入。

### 匯出專案

1. 舊位置在「檔案」面板按「匯出整個專案」。
2. 把下載的 `.json` 帶到新位置，在「檔案」面板按「還原整個專案」，選檔後再按一次確認。
3. 核對牆、卡片、連線、圖片、來源連結與分頁設定。

專案 JSON 只包含牆、圖片與專案設定，不包含備份、AI 提案、AI 紀錄或對話。還原時這些服務內部狀態會清除；不安全的來源連結會在預覽中標示並略過。

授權資料夾保存的是絕對路徑，換電腦或換資料位置後請到「資料夾」面板重新確認。
