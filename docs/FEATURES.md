# 功能與限制

[回 README](../README.md) · [發布現況與後續方向](ROADMAP.md)

文件核對日期：2026-11-06。以下對應 v0.2.0 的 [Tauri／Rust 桌面版](TAURI.md)，依儲存庫實作整理。乾淨 Windows 的完整安裝／升級／解除安裝矩陣、真實 CLI 端到端驗證及同條件 RAM／啟動速度量測仍未完成；不宣稱已量測到效能提升。

## 已提供的功能

| 面向 | 現有功能 | 目前限制 |
| --- | --- | --- |
| Windows Tauri／Rust 桌面版 | 安裝精靈、捷徑、系統匣、單一實例、服務設定與紀錄；`npm run app` 開發、`npm run dist` 打包 | 使用系統 WebView2，缺少時安裝程式需連網下載；未簽章、無自動更新 |
| 瀏覽器版 | `npm start` 建置 HTTP／MCP 執行檔並啟動 Rust 本機服務；macOS／Linux 可用 `./start.sh` 直接透過 Cargo 啟動 | 需 Rust 工具鏈；npm 開發及測試指令需 Node.js 24 以上，詳見 [建置說明](TAURI.md#windows-建置與啟動)；不是遠端託管服務 |
| 畫布 | 平移、縮放、全覽、框選、整組移動；推開重疊、對齊格線、全部重排 | 整理選取時固定其他卡片；分層線不隨卡片重排 |
| 卡片 | 線索卡、疑問便利貼、圖片、Markdown、來源、標籤、配色與自訂色、自由寬高、折疊、上下層、圖釘／膠帶、錨點等級 | 圖片最長邊縮至 1600px；沒有 PDF 閱讀與標註 |
| 關係 | 建立在其上（builds）、使用技術（uses）、待驗證疑問（question）；文字標籤、線型與自動／手動端點 | 三種固定類型；同兩張卡不能建立多條關係 |
| 組織 | 水平分層、源頭／重點錨點、清單跳轉與篩選、多牆分頁、排序、顏色、跨牆搜尋 | 分層不是容器；標籤篩選會淡化其他卡片；不是多人即時協作 |
| 操作入口 | 左側新增泡泡、齒輪選單與浮動功能面板；右側可收合 AI 案件夾 | 介面目前為繁體中文 |
| 外觀 | 六種背景、科技／擬真便利貼兩種風格、互動桌寵、減少動畫 | 偏好存在本機 localStorage，不隨專案 JSON 搬移 |
| 編輯保護 | 100 步復原／重做、批次複製貼上與刪除、每牆最多 20 份備份、保存狀態與衝突提示 | 切牆清空操作歷程；內部備份與原資料位於同一資料庫 |
| 匯入／匯出 | 單牆 JSON、JSON Canvas、整個專案 JSON；單牆匯入可預覽差異、逐項合併或確認取代 | 專案還原取代所有牆、圖片與 meta 並清除 AI 狀態；JSON Canvas 有降級項目，見下節 |

## AI 與資料邊界

- 內建對話透過 MCP 讀取目前牆與授權資料夾；外部 MCP 客戶端預設可讀全部牆，可在其 MCP 環境設定 `WALL_MCP_WALLS` 限制。
- `propose_changes` 只寫待審提案。套用前檢查衝突；刪除項目預設不勾選，未套用的預覽不改變牆面。
- 授權資料夾只讀文字檔：單檔上限 1 MiB、每次讀取最多 64 KiB、檔案清單每頁最多 100 筆。固定排除金鑰、憑證、資料庫及私密設定，詳細清單見 [README 安全與限制](../README.md#安全與限制)。
- 本機儲存不代表離線 AI。送出對話後，選用的 CLI 與模型服務會處理對話及讀取的材料。
- 外部 CLI 的工具權限由客戶端管理；案件圖譜的資料夾授權只約束自己的 MCP 讀檔工具。

## JSON Canvas 互通

「匯出 Canvas」保留卡片位置與尺寸、文字、來源、連線和分層，並以 `detective` 私有欄位補存案件圖譜資料。

- 圖片存在 `detective.images` 私有欄位，不能保證其他工具顯示。
- 匯出邊端點使用目前端點所在側；匯入端點側別時定位在該側中點，不完整保留側內比例。
- 外來 group 轉成分層，保留標題與 y 值；連到 group 的邊略過。
- 帶 `detective` 私有欄位的節點回匯時，可能優先使用私有文字，覆蓋其他工具修改過的公開 `text`。
- 與其他工具的完整往返相容性尚未驗證；正式搬移優先使用案件圖譜 JSON 或資料庫備份。

## Markdown、來源與離線使用

Markdown 透過 cdnjs 載入固定版本的 marked 12.0.2 與 DOMPurify 3.1.6，附 SRI。下載失敗時顯示原始純文字，畫布仍可用；不宣稱 Markdown 排版完全離線。

來源每行格式為 `名稱 | 路徑或網址 | 位置 | 摘錄`，後兩欄可省略，摘錄內的 `|` 保留。可使用 `http:`、`https:`、`file:`、`mailto:`、非 UNC 絕對路徑與相對路徑；不安全的 scheme、控制字元與編碼混淆會略過或拒絕。相對本機來源以 SQLite 檔案所在目錄為基準；本機檔案會檢查是否存在，網址標示為未檢查。

備份內容與搬移步驟見 [搬移與資料保存](MIGRATION.md)。
