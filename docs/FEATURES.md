# 現有功能與邊界

狀態基準：2026-10-31 原始碼與既有測試。

| 面向 | 已有 | 目前限制 |
| --- | --- | --- |
| 畫布 | 無限平移、縮放、全覽、框選、整組移動、依連線整理版面（全牆或選取卡片） | 整理時固定未選卡片；分層線不會跟著卡片移動 |
| 卡片 | 標題、Markdown、圖片、連結、六色、四種寬度、折疊、八方位釘點 | 圖片最長邊縮至 1600px；無 PDF 閱讀與標註 |
| 關係 | 三種固定類型、文字標籤、線型 | 不能自訂類型；同兩卡只能一條線 |
| 組織 | 水平分層、標籤篩選、多面牆分頁、排序與顏色、跨牆全文搜尋 | 分層不是容器；標籤篩選會淡化 |
| 編輯保護 | 100 步復原／重做、每牆最多 20 份備份 | 切牆清空操作歷程；備份與原資料位於同一 SQLite |
| 匯入 | 差異預覽、逐項勾選合併、兩次確認整份取代 | 卡片按 id 比對；不是多人即時協作 |
| 匯出 | 單牆 JSON 含圖片與來源位置/摘錄、JSON Canvas、整個專案 JSON（牆、圖片與 meta） | JSON Canvas 私有擴展不保證其他工具支援；專案還原會取代牆、圖片與 meta |
| 儲存 | 本機 Node/SQLite 保存權威資料；localStorage 存外觀偏好；畫面顯示最後保存時間 | 無跨裝置同步；服務失敗時只保留目前分頁記憶體內容並提供重試；還原專案或刪牆會清除對應 AI 狀態 |
| AI | 側欄「AI 對話」呼叫本機已登入的 Claude Code 或 codex，每面牆接續同一段對話；MCP 可讀牆、讀已授權專案資料夾、提出待審變更；側欄逐項預覽、套用、拒絕，AI 紀錄可回復；四種固定起手範本與自訂範本 | 預設禁止 AI 提案；需自行安裝並登入 CLI；資料夾只讀文字檔，固定排除金鑰／憑證／資料庫與私密設定，另有 1 MiB／64 KiB／100 檔案頁面上限；專案匯出不含提案、紀錄與對話；不直接呼叫模型 API；R10 模型品質需人工判斷 |

JSON Canvas 已知限制：圖片放在 `detective.images` 私有欄位；邊端點固定 top。外來 group 只保留標題與 y 值，連到 group 的邊略過。帶私有欄位的節點回匯時，可能優先使用舊的私有文字。正式互通測試與修正列在 ROADMAP.md，尚未實作。

Markdown 透過 cdnjs 載入 marked 12.0.2 與 DOMPurify 3.1.6，保留 SRI。下載失敗時顯示原始純文字，不宣稱完全離線的 Markdown 排版。

來源可用 `名稱 | 路徑或網址 | 位置 | 摘錄` 逐行記錄；位置與摘錄可省略，摘錄內的 `|` 會保留。來源只接受 `http:`、`https:`、`file:`、`mailto:`、非 UNC 絕對路徑與相對路徑；危險 scheme、控制字元與編碼混淆會被略過或拒絕。`file://`、絕對路徑與相對於 SQLite 檔案的路徑會檢查檔案是否存在；網址顯示為未檢查。
