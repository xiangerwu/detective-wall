# 功能路線圖

狀態基準：2026-11-02 原始碼與測試。

本文件把已交付的 P14／P15 與尚未完成方向分開；已交付功能不列為待辦。

## 已交付：P14／P15

- P14-A：框選刪除、複製貼上、分層與錨點清單、分層文字對比、卡片上下層。
- P14-B：卡片自由大小、連線端點、釘選或膠帶、真實便利貼與翻角、拍立得照片、錨點分級。
- P14-C：可拖曳、可縮放並反映 AI 狀態的桌寵。
- P14-D：推開重疊、對齊格線、全部重排三種整理版面模式。
- P15：六主題 × 兩種卡片風格的功能巡檢、UI/UX 一致性檢查與巡檢報告。

## 尚未完成方向

- U5：自訂關係名稱、線型與方向，並維持匯入、匯出與 MCP 的相容性。
- U6：與其他工具的正式 JSON Canvas 互通，明確列出所有降級項目。
- M1：以實際使用者登入的 Claude Code／codex 客戶端完成跨版本連線驗證與文件化。
- G：正式發布前的通用示例、乾淨截圖、完整版本核對與發布流程。
- 遠端服務、帳號與 OAuth 只有在確定需要跨電腦使用時才評估；目前服務維持本機限定。
